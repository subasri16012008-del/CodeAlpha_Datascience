
# Iris Flower Classification Using Python

## 1. Project Description
Iris Flower Classification is a Machine Learning project that classifies iris flowers into three different species using the Gaussian Naive Bayes algorithm.

The three species are:
- Setosa
- Versicolor
- Virginica

## 2. Objective
To predict the species of an iris flower based on its sepal length, sepal width, petal length, and petal width.

## 3. Technologies Used
- Python
- NumPy
- Scikit-learn
- Machine Learning

## 4. Dataset
The Iris dataset contains 150 flower samples with four features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## 5. Algorithm
Gaussian Naive Bayes is used to train the model and classify the flower species.

## 6. Installation

Install the required libraries using:

```bash
pip install numpy scikit-learn
```

## 7. How to Run

1. Download or clone the project.
2. Open the project in VS Code.
3. Install the required libraries.
4. Run the Python program.

```bash
python iris.py
```

## 8. Output
The program displays:
- Prediction accuracy
- Confusion matrix
- Classification report

## 9. Result
The Iris Flower Classification model successfully predicts the flower species using the Gaussian Naive Bayes algorithm.

## 10. Conclusion
This project demonstrates how Machine Learning can be used to classify flowers based on their measurements.
