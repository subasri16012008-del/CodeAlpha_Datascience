# Unemployment Analysis with Python

## Description
This project analyzes unemployment rates using Python and identifies trends and the impact of COVID-19.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Features
- Data cleaning and preprocessing
- Unemployment rate analysis
- COVID-19 impact analysis
- Monthly and yearly trend analysis
- Data visualization

## Installation
```bash
pip install numpy pandas matplotlib seaborn
```

## Run
```bash
python unemployment_analysis.py
```

## Result
Successfully analyzed unemployment trends and visualized the impact of COVID-19 using Python.
